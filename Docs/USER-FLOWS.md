# User Flows — SG Properties

## 1. First visit: doorway choice
1. Visitor opens the website.
2. Sees architectural double-door landing.
3. Chooses **REITs** or **Real Estate**.
4. Selected panel animates open.
5. Visitor lands on the corresponding section.
6. A visible navigation control allows switching sections.

## 2. REIT discovery
1. Visitor selects REITs.
2. Sees available investment opportunities.
3. Opens Azure by Lapis.
4. Reviews location, investment amount, unit information, timeline, approved return/tax statements, and risk disclosures.
5. Selects Enquire.
6. Completes contact form and consent.
7. Receives confirmation; SG Properties sales team receives lead notification.

## 3. International property discovery
1. Visitor selects Real Estate.
2. Sees country selector.
3. Selects a country, e.g. Philippines.
4. Sees published properties in that country.
5. Filters by city, bedrooms, type, price, or area.
6. Opens a property such as LePont or The Mantawi Residences.
7. Reviews gallery, overview, unit mix, location, and availability.
8. Enquires about the selected property.
9. Lead is linked to that property in admin.

## 4. Admin: create property
1. Admin signs in.
2. Opens Properties → Add Property.
3. Enters title, slug, project, country, city, address, type, description.
4. Adds unit types, areas, prices, and availability where known.
5. Uploads images and writes alt text.
6. Completes SEO fields.
7. Saves as draft.
8. Previews the public page.
9. Reviewer verifies facts and permissions.
10. Authorised admin publishes; relevant routes and sitemap are revalidated.

## 5. Admin: create investment
1. Admin opens Investments → Add Offering.
2. Enters project and location information.
3. Enters amount, currency, unit details, area, timeline.
4. Adds return, tax, and appreciation statements only with source/approval metadata.
5. Adds legal structure, jurisdiction, regulatory status, and risk disclosure.
6. Saves draft and submits for review.
7. Reviewer checks supporting documents and approved copy.
8. Authorised admin publishes.

## 6. Lead management
1. Sales user opens Leads.
2. Filters New leads by date, country, project, or assigned user.
3. Opens a lead and reviews enquiry context.
4. Assigns owner, updates status, and adds internal notes.
5. Follows up outside the website.
6. Records outcome.

## 7. Empty and error states
- No properties in country: explain that no current listings are available and provide a general enquiry CTA.
- No filter results: clear filters action.
- Form error: preserve valid inputs and show field-level guidance.
- Network failure: show retry message without losing user-entered content where feasible.
