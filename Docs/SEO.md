# SEO Strategy — SG Properties

## 1. SEO goals
Build discoverable, high-quality landing pages for investment opportunities, property projects, cities, and countries without generating thin or duplicate pages.

## 2. URL structure
- `/` — doorway / brand home
- `/reits` — investment opportunities
- `/reits/azure-by-lapis`
- `/real-estate` — country selector
- `/real-estate/philippines`
- `/real-estate/philippines/le-pont-rlc-residences`
- `/real-estate/philippines/the-mantawi-residences`
- `/about`
- `/contact`

Use lowercase, readable, stable slugs. Add 301 redirects when published slugs change.

## 3. Metadata
Every indexable page requires:
- Unique title and meta description.
- Canonical URL.
- Open Graph and social image.
- Correct robots directives.
- Descriptive H1 and logical heading hierarchy.
- Helpful image alt text.

## 4. Content strategy
- Write unique country introductions with actual market and inventory context.
- Write project pages from verified facts, not copied developer marketing text.
- Include location, developer, unit mix, area units, availability date, and currency where confirmed.
- Avoid keyword stuffing and unsupported superlatives.
- Do not publish empty country pages solely to target keywords.
- Clearly distinguish educational content from financial promotion.

## 5. Structured data
Use appropriate schema only when page content qualifies:
- Organization / RealEstateAgent as appropriate to the actual business.
- BreadcrumbList.
- Residence / Apartment / Offer only when the data and Google guidelines support it.
- Avoid fabricated ratings, reviews, prices, availability, or financial metrics.

## 6. Technical SEO
- Generate `sitemap.xml` from published records.
- Generate `robots.txt`.
- Set canonical URLs.
- Use server-rendered content.
- Optimise images with Next Image and descriptive filenames.
- Ensure mobile usability and Core Web Vitals.
- Add breadcrumbs to detail pages.
- Prevent admin, preview, search parameter, and unpublished pages from indexing.
- Configure 404 and redirect handling.
- Add Search Console and analytics after ownership and consent configuration.

## 7. Example keyword themes
Use as research themes, not guaranteed ranking targets:
- international real estate investment
- properties in Dubai / UAE
- properties in the Philippines
- apartments in Pasig City
- condos in Mandaue City Cebu
- Boracay condominium opportunities
- real estate investment opportunities India
- property investment advisory

Validate search demand, intent, competition, and compliance before creating dedicated pages.
