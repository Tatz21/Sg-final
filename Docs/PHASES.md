# Delivery Roadmap — SG Properties

## Phase 0 — Discovery and verification
- Confirm SG Properties brand assets, contact information, legal entity details, and target markets.
- Verify Azure by Lapis facts, legal structure, return wording, tax statement, appreciation basis, minimum amount, and handover.
- Confirm project facts and media permissions for LePont, The Mantawi Residences, and Boracay.
- Confirm whether ₹225,000 is an investment minimum, booking amount, or indicative starting price.
- Approve disclosures and privacy requirements.

**Exit criteria:** approved content sheet, sitemap, brand direction, and project scope.

## Phase 1 — Foundation
- Scaffold Next.js App Router + TypeScript.
- Configure Tailwind, shadcn/ui, Nunito, linting, formatting, and environment validation.
- Configure PostgreSQL and Prisma.
- Implement authentication, roles, database migrations, and audit logging.
- Build shared layout and responsive navigation.

## Phase 2 — Public experience
- Build animated doorway landing.
- Build REIT listing and investment detail templates.
- Build country selector and country property results.
- Build property detail template and enquiry forms.
- Add About, Contact, Privacy, Terms, and disclosure pages.
- Add metadata, sitemap, robots, and structured data.

## Phase 3 — Admin CMS
- Dashboard and role-aware navigation.
- CRUD for properties, units, investments, countries, cities, developers.
- Media upload and ordering.
- Draft, preview, publish, archive.
- Lead inbox, assignment, status, notes, and exports.
- SEO and site settings.

## Phase 4 — Content loading and QA
- Load approved Azure content.
- Load verified Philippines project details.
- Add Boracay only when project details are confirmed.
- Test all country, property, and enquiry flows.
- Accessibility, performance, security, and responsive testing.

## Phase 5 — Launch
- Configure production database, storage, email, domains, analytics, and monitoring.
- Configure redirects and Search Console.
- Run production smoke tests.
- Train SG Properties admins.
- Launch and monitor.

## Phase 6 — Enhancements
- CRM integration.
- Multi-language content.
- Currency conversion.
- Advanced search and maps.
- Investor document room and gated resources.
- Campaign and lead analytics.

## Dependencies and blockers
- Approved brand assets and licensed imagery.
- Verified investment and project facts.
- Legal review of investment marketing claims.
- Production contact details and lead notification recipients.
- Privacy policy and terms approved for operating jurisdictions.
